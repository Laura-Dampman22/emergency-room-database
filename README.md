# Emergency Room Triage and Patient Flow Database

A relational database project designed to track emergency room patient flow, support analysis of the triage process, and identify opportunities to improve emergency room efficiency.

## Project Overview

This project was completed for my Database Systems course and was inspired by challenges facing emergency departments in Chester County, Pennsylvania. Following the closures of Brandywine Hospital and Jennersville Hospital, the remaining emergency departments in the Chester County area faced increased patient volume, contributing to longer wait times, capacity challenges, patient transfers, and increased workloads for healthcare staff.

I designed the Emergency Room Triage and Patient Flow Database to explore how data could be used to improve the efficiency and effectiveness of the emergency room intake process. The database was designed to track patient flow and emergency room activity in order to identify areas for improvement, support resource allocation, and better understand factors that may contribute to patient wait times.

## Project Goals

- Streamline the emergency room triage process
- Track patients throughout the emergency room workflow
- Analyze patient flow and wait times
- Support more effective allocation of emergency room resources
- Identify areas of the intake and treatment process that may need improvement
- Organize patient, staff, visit, and treatment information within a relational database
- Use SQL queries to analyze emergency room activity and operational data

## What I Learned

Through this project, I learned the process of designing and creating a relational database from start to finish, beginning with identifying a real-world problem and determining the data needed to support the proposed solution.

I gained experience defining data requirements, identifying entities and relationships, creating an ER diagram, translating the design into a relational schema, and implementing the database using PostgreSQL and SQL.

I also strengthened my ability to develop SQL queries to retrieve and analyze information across related tables. Most importantly, this project helped me understand how database design and data analysis can be used to examine real-world operational problems, such as patient flow, wait times, and resource allocation.
